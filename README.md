# Фильтрация транзакций по категориям (Transaction Analyzer)

Этот модуль предоставляет инструмент для анализа личных финансов, позволяющий фильтровать транзакции по определенной категории за последние три месяца от заданной даты. Проект разработан на **Python 3.14** с использованием библиотек **Pandas** и **Poetry**.

## 🛠️ Стек технологий

* **Python** >= 3.14
* **Pandas** — для обработки и фильтрации табличных данных
* **Poetry** — для управления зависимостями и окружением
* **Pytest** — для автоматизированного тестирования кода

## 📊 Описание функции

Основная функция `spending_by_category` фильтрует готовый DataFrame с транзакциями.

```python
import pandas as pd

def spending_by_category(transactions: pd.DataFrame,
                         category: str,
                         date: str | None = None) -> pd.DataFrame:
```

### Параметры:
* `transactions` (`pd.DataFrame`): Таблица с транзакциями. Обязательно должна содержать колонки `date` и `category`.
* `category` (`str`): Название категории для фильтрации (например, `"Супермаркеты"`).
* `date` (`str | None`, по умолчанию `None`): Конечная дата для отсчета в формате `YYYY-MM-DD`. Если передано значение `None`, функция автоматически использует **текущую системную дату**.

### Что возвращает:
Функция возвращает **новый `pd.DataFrame`**, содержащий только те транзакции по указанной категории, которые были совершены в интервале **[Конечная дата - 3 месяца; Конечная дата]**. Исходный датафрейм при этом **не изменяется**.

## 💻 Пример использования

Пример чтения данных из файла `data/operations.xls` и вызова функции:

```python
import pandas as pd
from src.reports import spending_by_category  # Укажите ваш правильный путь импорта

# 1. Загружаем транзакции из Excel-файла
df_operations = pd.read_excel('data/operations.xls')

# 2. Получаем траты по категории "Супермаркеты" за последние 3 месяца от 2 октября 2026 года
result_df = spending_by_category(
    transactions=df_operations,
    category='Супермаркеты',
    date='2026-10-02'
)

# 3. Выводим результат
print(result_df)
```

## 🧪 Запуск тестов

В проекте настроены модульные тесты для проверки корректности работы фильтров по датам, отсутствующим категориям и контроля мутации данных.

Запустить тестирование с помощью `pytest` можно прямо через Poetry:

```bash
poetry run pytest
```

Для запуска тестов с подробным выводом (verbose):

```bash
poetry run pytest -v
```
